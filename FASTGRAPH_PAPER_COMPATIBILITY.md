# FastGraph Paper Compatibility Note

This is a pinned fork of the third-party CLOVER project, used only for the
d=3 comparison reported in the FastGraph paper. It is not part of the
FastGraphCompute library or its public API.

The `pca-fgc-paper-v1.2.0` tag preserves the Falcon A100 build adaptation,
the paper's `k=40` alignment, and the mesh-path workflow used to produce the
checked-in comparison result. Refer to the upstream CLOVER project for
general installation, development, and citation guidance.
